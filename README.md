Entry for the make.fun bounty [Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44): one original fortune-cookie line for a software developer, at most 120 characters.

## The line

> "The code you inherit is a letter from a developer who left before saying goodbye."

Why this line: a tired senior engineer inherits code every day, and the truest thing about legacy code is that it arrives without its author — no handover, no goodbye, just the code. So the line turns the codebase itself into the farewell letter the author never got to write. It reads like a real fortune cookie (one short balanced sentence, second person, lands in a single breath), it is true about a developer's day, and the twist — the farewell was never said, the code is the only message left — rewards a second read.

## Run

```sh
node main.ts
```

Writes the fortune to `/output/entry.txt` (81 characters, no trailing newline), deterministically.
